# essies_product_launch_dashboard

An end-to-end Power BI project covering data preparation, transformation, data modeling, and interactive sales dashboards.

## 1. Project Overview

This project analyzes retail sales, online sales, and campaign performance using Microsoft Power BI. It transforms sales data into interactive dashboards that provide insights into product demand, sales trends, profitability, customer activity, and promotional performance to support data-driven business decisions.

## 2. Problem Statement

Sales data from different channels and promotional campaigns can be challenging to analyze without a structured reporting system. Identifying sales trends, comparing product performance, and understanding profitability can become time-consuming. This project uses interactive Power BI dashboards to organize and visualize sales information, making it easier to compare performance, identify business trends, and support informed decision-making.

## 3. Dataset

Source: CSV files used for the project.
Data preparation: Data was loaded, cleaned, and transformed before visualization.

## 4. Tools and Technologies

Microsoft Power BI Desktop, 
Power Query, 
Data Cleaning and Transformation, 
Data Modeling and Relationships, 
DAX Measures, 
Data Visualization

## 5. Methodology

1. Data Loading: Imported the project data from CSV files into Power BI.
2. Data Cleaning: Prepared the data and handled data quality issues as required.
3. Data Transformation: Used Power Query to transform the data for analysis.
4. Data Modeling: Organized tables and relationships to support reporting.
5. Measure Preparation: Used relevant measures for sales, quantity, and profit analysis.
6. Dashboard Development: Designed charts, summary cards, category comparisons, and filters.
7. Report Organization: Arranged visual elements across three dashboard pages to present the analysis clearly.

## 7. Key Observations

1. The retail dashboard helps analyze retailer performance, product demand, and category-wise sales trends.
2. The online sales dashboard provides insights into sales, profit, and product performance.
3. The campaign dashboard enables comparisons of promotional sales across products and retail counters.
4. The dashboards help stakeholders identify business trends, evaluate performance, and make data-driven decisions.

## 8. Results and Conclusion

The project transforms raw sales data into three interactive Power BI dashboards covering retail sales, online sales, and campaign performance. These dashboards provide a clear view of business trends and support data-driven analysis for sales planning, product performance evaluation, and campaign assessment.
